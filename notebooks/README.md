# Exploratory Notebooks

This folder contains experimental notebooks used for initial Exploratory Data Analysis (EDA) and prototyping our Bayesian Inference (BI) pipelines.

> ❗ **Note:** These notebooks are **not** used to run the core project engine. They are kept here strictly for reference, quick testing, and development transparency.

## Folder Structure

### 📊 `eda/`
Contains 3 notebooks focused on ingesting the generated data and plotting it across a variety of visual configurations. It mainly serves as a descriptive visual baseline that does not perform any rigorous analyses.

### 🧬 `bayesian_inference/`
Contains 3 notebooks used to prototype, sample, and validate our "fixed", "random", and "hierarchical" modes before migrating the inference logic into production code.
