# Exploratory Notebooks

This folder contains experimental notebooks used for initial Exploratory Data Analysis (EDA) and prototyping our Bayesian Inference (BI) pipelines.

> ❗ **Note:** These notebooks are **not** required to run the core project engine. They are kept here strictly for reference, quick testing, and development transparency.

## Folder Structure

### 📊 `eda/`
Contains 3 notebooks dedicated to initial data ingestion checks, data type validations, market volatility summaries, and correlation heatmaps across the various London rental configurations.

### 🧬 `bayesian_inference/`
Contains 3 notebooks used to prototype, sample, and validate our baseline, random, and hierarchical models before migrating the inference logic into production code.
