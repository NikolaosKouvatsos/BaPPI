# 🧮 Theoretical Framework: Bayesian Inference Engine

This document outlines the mathematical transition from **Data Generation** to **Statistical Inference** used within the `src/` directory.

## 1. The Generative Model (Simulation)
We define the relationship between property features and price as a conditional probability distribution. For a given property with features $X$, the price $y$ is generated by:

$$P(y \mid X, M) = f(X, \theta_M) + \epsilon$$

Where:
*   **$X$**: Multivariate feature vector (rooms, distance, amenities).
*   **$M$**: The model identifier (Case A: Owner, Case B: Agent).
*   **$\theta_M$**: Model-specific parameters (e.g., Agent Premium $\beta_{agent}$).
*   **$\epsilon$**: Stochastic noise representing market volatility, where $\epsilon \sim \mathcal{N}(0, \sigma^2)$.

## 2. Inverting the Function (Inference)
To determine if a specific data point $(X, y)$ belongs to Model A or Model B, we apply **Bayes' Theorem** to "invert" the generative process:

$$P(M \mid y, X) = \frac{P(y \mid X, M) P(M)}{P(y \mid X)}$$

### Components of the Inversion:
1.  **The Likelihood $P(y \mid X, M)$**: 
    This is the core of the engine. It calculates the probability density of the observed price $y$ under the assumption that Model $M$ is true. If the observed price is far from the model's predicted mean, the likelihood decreases exponentially.
    
2.  **The Prior $P(M)$**: 
    Our baseline belief in the absence of price data (defaulted to 50/50).

3.  **The Evidence $P(y \mid X)$**: 
    A normalizing constant representing the total probability of the price under all considered models:
    $P(y \mid X) = \sum_{M \in \{A, B\}} P(y \mid X, M)P(M)$

## 3. Model Comparison (The Bayes Factor)
The engine decides between cases by calculating the **Posterior Odds Ratio**:

$$\frac{P(B \mid y, X)}{P(A \mid y, X)} = \underbrace{\frac{P(y \mid X, B)}{P(y \mid X, A)}}_{\text{Bayes Factor}} \times \frac{P(B)}{P(A)}$$

*   **If Ratio > 1**: Evidence favors **Model B (Agent)**.
*   **If Ratio < 1**: Evidence favors **Model A (Owner)**.

## 4. Implementation Strategy
*   **Forward Pass**: `gen_prop_data.py` simulates $X$ and $y$ by injecting a hidden bias for Case B.
*   **Backward Pass**: The inference engine calculates the residuals $(y - \hat{y})$ for both models and maps them back to the Normal PDF to extract the likelihoods and final posterior probability.
